# El circuito en vivo — Sol, LDR y LED

Simulación interactiva para estudiantes de 3.º año: un control deslizante de intensidad solar
actualiza en vivo cada etapa de la ruta del dato (voltaje analógico → lectura ADC → decisión/`map()`
→ orden `analogWrite()` → salida PWM → brillo del LED), junto con un esquema del circuito
Sol – LDR – Arduino UNO – resistencia – LED.
